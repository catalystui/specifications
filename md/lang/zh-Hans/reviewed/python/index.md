### 警告

* Python 提供的是无限精度整数，而不是定宽整数原语。
* Python 的 `float` 通常是双精度，但不是独立的定宽族。
* 某些底层内存行为可能需要 `ctypes` 或实现特定行为。
* Python 类型提示不会在运行时强制执行。
* Python 支持属性，但 setter 行为可以省略。
* Python 可通过标准库特性建模若干结构，但并不存在原生结构类型。

### 失败项

* Python 不提供大多数所需的定宽标量数值类型。
* Python 不提供专用的标量 32 位浮点类型。
* Python 不提供真正的语言级常量。
* Python 不将过程与函数分开定义。
* Python 不提供原生指针支持。
* Python 不提供原生接口支持。
