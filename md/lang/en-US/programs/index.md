# Verification Programs

CatalystUI Verification Programs organize the different ways a language, service, framework, application, library, or system may become **CatalystUI Verified**.

Each program defines its own review scope, requirements, and verification process.

## Languages

Programming Language Verification reviews whether a programming language can reasonably represent the foundational data and relationship concepts required by CatalystUI.
