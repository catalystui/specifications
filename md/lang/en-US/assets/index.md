# CatalystUI Verified Asset Guidelines

The CatalystUI Verified mark indicates that a specific product, service, language, specification, implementation, or other asset has completed a CatalystUI verification review.

Because the mark represents a verification claim, it must always be used in a way that allows users to confirm exactly what has been verified. Every use of the CatalystUI Verified mark must be paired with the direct CatalystUI verification review page for the specific asset being represented.

The mark must not be used by itself, and it must not imply verification of any asset, organization, product line, service, or implementation other than the one described on the linked review page.

## Official Assets

Official CatalystUI Verified assets are available at:

```txt
https://www.catalystui.org/assets/verification/
```

Verified users may either download and re-host the applicable assets or reference them directly from the CatalystUI website.

CatalystUI provides direct asset hosting as a courtesy. This courtesy must be used respectfully and reasonably. Any abuse, excessive automated requests, excessive API calls, hotlinking behavior that creates unreasonable load, or other misuse of CatalystUI-hosted assets may result in revocation of the associated verified status.

If CatalystUI-hosted assets are used directly, the usage must still comply with these guidelines, including the requirement that the CatalystUI Verified mark be paired with the direct verification review page for the specific asset being represented.

## Required Link

Whenever the CatalystUI Verified mark is displayed digitally, it must include a visible and accessible link to the applicable verification review page.

For example:

```md
[![CatalystUI Verified](./catalystui-verified.png)](https://catalystui.org/specifications/languages/verified/java/)
```

The link must point directly to the CatalystUI verification review page for the verified asset. It must not point only to the CatalystUI homepage, a general verification index, a product homepage, or an unrelated marketing page.

## Printed Materials

If the CatalystUI Verified mark appears on printed materials, the direct CatalystUI verification review URL must also be printed near the mark or in a clearly associated location.

Printed materials include, but are not limited to:

* Product packaging
* Printed documentation
* Flyers
* Posters
* Business cards
* Conference materials
* Physical advertisements

For example:

```txt
CatalystUI Verified
https://catalystui.org/specifications/languages/verified/java/
```

## Valid Usage

Use of the CatalystUI Verified mark is valid only when all of the following are true:

1. The asset has an active CatalystUI verification review page.
2. The mark refers only to the asset described by that review.
3. The mark is paired with the direct CatalystUI verification review URL.
4. The link or printed URL is clear enough for users to verify the claim.

## Invalid Usage

The CatalystUI Verified mark must not be used:

* Without a direct link or printed URL.
* To imply verification of an entire company when only one asset has been verified.
* To imply verification of any product, service, language, specification, implementation, or other asset that has not been reviewed.
* To imply current verification after the applicable review has expired, been revoked, or become invalid.
* In a way that hides, obscures, removes, or separates the verification URL from the mark.
* In any way that could mislead users, customers, developers, organizations, or the public into believing an asset has been reviewed or approved by CatalystUI when it has not.

## Unauthorized Usage

The CatalystUI Verified mark may only be used by assets which have received explicit verification from CatalystUI and remain in good standing.

Any use of the CatalystUI Verified mark without permission is strictly prohibited.

### Constitutions

Unauthorized use includes, but is not limited to:

* Displaying the CatalystUI Verified mark without an active verification.
* Claiming CatalystUI verification before a review has been completed.
* Using the mark for an asset other than the one specifically verified.
* Using the mark without linking to the applicable CatalystUI verification review page.
* Modifying, obscuring, or presenting the mark in a misleading way.
* Continuing to use the mark after verification has expired, been revoked, or become invalid.

### Consequences

Any person, organization, project, product, service, or entity that uses the CatalystUI Verified mark without permission will become permanently ineligible for CatalystUI verification.

This ineligibility applies regardless of:

* Fees paid.
* Applications submitted.
* Review requests made.
* Previous approvals.
* Future corrections.
* Changes in ownership, branding, or presentation.

Unauthorized use demonstrates a failure to respect the verification process itself. Because CatalystUI verification exists to provide clarity, trust, and accountability, misuse of the mark is treated as a direct violation of that trust.

### Existing Verifications

If unauthorized use is made by a person, organization, project, product, service, or entity that already holds one or more CatalystUI verifications, all existing verifications immediately become void.

Void verifications may be removed from CatalystUI listings, marked as invalid, or otherwise updated to indicate that the verification is no longer recognized.

Once a verification is voided due to unauthorized usage, the affected person, organization, project, product, service, or entity becomes permanently ineligible for future CatalystUI verification.

### No Refunds

Fees paid for CatalystUI verification, review, application, renewal, or related services do not override these rules.

If unauthorized usage is discovered before, during, or after a review process, CatalystUI may reject the application, terminate the review, void existing verifications, and retain any fees already paid to the fullest extent permitted by applicable law.

### Reporting Unauthorized Use

If you believe the CatalystUI Verified mark is being used without authorization, please contact CatalystUI with relevant details, including the name of the asset, the location where the mark appears, and any supporting evidence.

Unauthorized usage may be reviewed by CatalystUI at its sole discretion.

## Summary

The CatalystUI Verified mark is not merely a badge. It is a verification claim which helps users confirm that a specific asset has been reviewed by CatalystUI.

For that claim to be valid, users must always be able to follow the mark back to the CatalystUI verification review page for the exact asset being represented. If users cannot verify the claim, the mark must not be used.

Using the mark without permission breaks that trust. Any unauthorized use results in permanent ineligibility for CatalystUI verification, and any existing verifications immediately become void.
