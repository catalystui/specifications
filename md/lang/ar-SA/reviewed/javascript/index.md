# تفاصيل المراجعة

## JavaScript

### نظرة عامة

تمت مراجعة لغة البرمجة JavaScript مقابل مواصفتي FDEFSPEC (Rev. 1) و FRELSPEC (Rev. 1) اعتبارًا من 7 يوليو 2026.

#### بيان المراجعة

مع أن JavaScript تستطيع تمثيل بعض المفاهيم المطلوبة من خلال الكائنات والدوال والمصفوفات وسلوك اللغة المدمج، فإن هذه الآليات ليست كافية لتلبية مواصفات CatalystUI المطبقة على مستوى اللغة.

تقيّم هذه المراجعة JavaScript نفسها، لا نظام JavaScript البيئي المحيط بها. ولا تُعامل واجهات برمجة المتصفح، وواجهات Node.js، وواجهات Deno، وواجهات Bun، وواجهات Web APIs، و TypeScript، و WebAssembly، والمكتبات الخارجية، والتحقق المخصص على أنها دعم على مستوى اللغة.

ونظرًا إلى أن JavaScript تفتقر إلى كثير من أنواع الأعداد القياسية ذات العرض الثابت المطلوبة، ولا توفر ترميزات النص المطلوبة كميزات لغوية، ولا تعرّف عدة بُنى مطلوبة خاصة بالنظام والذاكرة والخيوط التنفيذية والمركبات، فإننا لا نعتقد أن JavaScript توفر أساسًا مستقرًا بما يكفي لتنفيذ متوافق مع CatalystUI دون بنية إضافية كبيرة.

ونتيجة لذلك، لم تُمنح JavaScript حالة الاعتماد من CatalystUI للغات البرمجة.

#### افتراضات المراجعة

تطبق هذه المراجعة معيارًا صارمًا على مستوى اللغة. إذا لم يكن الحكم مدعومًا صراحةً من JavaScript نفسها، فإنه يوسم على أنه غير متحقق.

تُستبعد من التحقق واجهات API التي يوفرها المضيف، والسلوك الخاص بالتنفيذ، والمكتبات الخارجية، والمحوّلات البرمجية، وأنظمة الأنواع، والتحقق المخصص في وقت التشغيل.

### التحذيرات

* تستطيع JavaScript تمثيل كثير من القيم العددية من خلال `Number`، لكن `Number` نوع عددي ذو فاصلة عائمة من 64 بت.
* توفر JavaScript النوع `BigInt`، لكن `BigInt` ذو عرض اعتباطي.
* توفر المصفوفات النمطية عروض تخزين ثنائي، لا أنواعًا قياسية لغوية.
* تستخدم سلاسل JavaScript وحدات ترميز UTF-16، لا قيم ترميز نص صريحة.
* يحمي `const` الارتباطات، لا قيم الكائنات.

### الإخفاقات

* لا توفر JavaScript معظم أنواع الأعداد القياسية ذات العرض الثابت المطلوبة.
* لا توفر JavaScript نوعًا قياسيًا مخصصًا للفاصلة العائمة من 32 بت.
* لا توفر JavaScript ترميزات ASCII أو CP1252 أو UTF-8 أو UTF-16LE على مستوى اللغة.
* لا توفر JavaScript بُنى ملفات أو تدفقات على مستوى اللغة.
* لا توفر JavaScript بُنى عناوين أو مؤشرات على مستوى اللغة.
* لا توفر JavaScript بُنى عمليات أو خيوط تنفيذية أو موزعات على مستوى اللغة.
* لا توفر خصائص JavaScript عضوًا صريحًا ذا مفتاح مدعومًا بخريطة موصلات Get/Set مطلوبة.
* لا توفر JavaScript بنى أو واجهات.
