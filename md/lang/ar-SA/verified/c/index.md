# تفاصيل التحقق

## C

### نظرة عامة

![Verified Indicator](https://www.catalystui.org/images/verification/verified-logo-generic.png)


تم التحقق من لغة البرمجة C مقابل مواصفتي FDEFSPEC (Rev. 1) و FRELSPEC (Rev. 1) اعتبارًا من 7 يوليو 2026.

#### بيان حسن النية

نعتقد بحسن نية أن لغة البرمجة C تستطيع تمثيل المفاهيم والأحكام المحددة في المواصفات التالية تمثيلًا معقولًا، وأنه يمكن استخدامها لتنفيذ أنظمة متوافقة مع هذه المواصفات.

#### بيان المراجعة

توفر C دعمًا قويًا منخفض المستوى لتمثيل البيانات التأسيسية، والوصول إلى الذاكرة، والملفات، والتدفقات، والإجراءات، والدوال، والبنى، والتنفيذ المباشر الموجه إلى النظام.

مع أن C لا توفر عدة بُنى مركبة كائنية التوجه بشكل أصلي، فإن هذه القيود معزولة في أحكام مركبة محددة من FRELSPEC وموثقة أدناه. لا تمنع هذه الإخفاقات اعتبار C ضمن المواصفة إجمالًا، لكنها ينبغي أن تكون مفهومة عند استخدام C لتنفيذات متوافقة مع CatalystUI.

#### افتراضات المراجعة

تفترض هذه المراجعة دعم C القياسية الحديثة حيث تُذكر الميزات المعتمدة على الإصدار. ويفترض دعم الأعداد الصحيحة ذات العرض الدقيق توفر أنواع `<stdint.h>` المقابلة من التنفيذ.

تتعامل هذه المراجعة مع C كلغة تمثيل منخفضة المستوى. ويمكن تمثيل الترميزات الدقيقة على مستوى البايت مباشرةً من خلال مصفوفات البايتات وجداول البحث ومنطق التحليل الصريح عندما لا يكون هناك codec قياسي مسمى.

### التحذيرات

* تعتمد أنواع الأعداد الصحيحة ذات العرض الدقيق على دعم التنفيذ.
* يمكن تمثيل CP1252 بايتًا ببايت، لكن لا يوجد codec قياسي مسمى.
* يتطلب تسلسل UTF-16LE معالجة صريحة لترتيب البايتات.
* قد تُحذف الخيوط القياسية في بعض تنفيذات C.
* يمكن محاكاة الأنماط كائنية التوجه يدويًا، لكنها ليست بُنى لغوية أصلية.

### الإخفاقات

* لا توفر C أعضاء طرق أصلية.
* لا توفر C خصائص أصلية.
* لا توفر C أصنافًا أصلية.
* لا توفر C واجهات أصلية.
