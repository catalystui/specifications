# تفاصيل التحقق

## Java

### نظرة عامة

![Verified Indicator](https://www.catalystui.org/images/verification/verified-logo-generic.png)


تم التحقق من لغة البرمجة Java مقابل مواصفتي FDEFSPEC (Rev. 1) و FRELSPEC (Rev. 1) اعتبارًا من 7 يوليو 2026.

#### بيان حسن النية

نعتقد بحسن نية أن لغة البرمجة Java تستطيع تمثيل جزء كبير من المفاهيم والأحكام المحددة في المواصفات التالية تمثيلًا معقولًا، وأنه يمكن استخدامها لتنفيذ أنظمة متوافقة مع هذه المواصفات.

#### افتراضات المراجعة

تفترض هذه المراجعة دعم Java الحديثة حيث تُذكر الميزات المعتمدة على الإصدار. وقد تتطلب ميزات مثل استنتاج المتغيرات المحلية، و records، والوصول إلى الذاكرة الخارجية إصدارات Java لاحقة.

### التحذيرات

* لا تحتوي Java على دعم أصلي لأنواع الأعداد غير الموقعة، مما قد يتطلب التوسيع أو تمثيلات بديلة لبعض الأحكام.
* قد يتطلب سلوك عناوين الذاكرة المباشرة ونمط المؤشرات دعم Java 22+ Foreign Function and Memory API.
* لا تحتوي Java على صياغة خصائص أصلية، مما يتطلب طرق getter و setter بدلًا من ذلك.

### الإخفاقات

* لا توفر Java ترميز CP1252 كـ charset قياسي مضمون، مما يتطلب دعمًا خاصًا بالتنفيذ أو مكتبات إضافية أو معالجة مخصصة للامتثال الكامل.
* لا توفر خصائص Java عضوًا صريحًا ذا مفتاح مدعومًا بخريطة موصلات Get/Set مطلوبة.
