### 警告

* JavaScript 可以通过 `Number` 表示许多数值，但 `Number` 是 64 位浮点数值类型。
* JavaScript 提供 `BigInt`，但 `BigInt` 是任意宽度的。
* Typed arrays 提供的是二进制存储视图，而不是标量语言类型。
* JavaScript 字符串使用 UTF-16 代码单元，而不是显式文本编码值。
* `const` 保护的是绑定，而不是对象值。

### 失败项

* JavaScript 不提供大多数所需的定宽标量数值类型。
* JavaScript 不提供专用的标量 32 位浮点类型。
* JavaScript 不将 ASCII、CP1252、UTF-8 或 UTF-16LE 作为语言级文本编码提供。
* JavaScript 不提供语言级文件或流构造。
* JavaScript 不提供语言级地址或指针构造。
* JavaScript 不提供语言级进程、线程或调度器构造。
* JavaScript 属性并不提供由所需 Get/Set 访问器映射支持的显式键控成员。
* JavaScript 不提供结构或接口。
