# جزئیات بازبینی

## Python

### نمای کلی

زبان برنامه‌نویسی Python در برابر مشخصات FDEFSPEC (Rev. 1) و FRELSPEC (Rev. 1) تا تاریخ ۷ ژوئیهٔ ۲۰۲۶ بازبینی شده است.

#### بیانیهٔ بازبینی

هرچند Python می‌تواند بسیاری از مفاهیم لازم را از طریق نوع‌های داخلی، objectها، functionها، classها، ماژول‌های کتابخانهٔ استاندارد و اعتبارسنجی سفارشی نمایش دهد، این سازوکارها برای برآورده‌کردن مشخصات قابل‌اعمال CatalystUI در سطح زبان کافی نیستند.

Python از رمزگذاری متن، fileها، streamها، objectها، functionها، classها، propertyها، processها، threadها و اجرای dispatched از طریق رفتار داخلی و کتابخانهٔ استاندارد خود پشتیبانی قوی دارد. با این حال، Python نوع‌های عددی scalar با عرض ثابت مورد نیاز را فراهم نمی‌کند، constantهای واقعی تعریف نمی‌کند، و برای چندین سازه به رفتار runtime پویا تکیه می‌کند؛ سازه‌هایی که زبان‌های تأییدشدهٔ دیگر می‌توانند مستقیم‌تر بیان کنند.

به همین دلیل، ما باور نداریم Python بدون زیرساخت اضافی قابل‌توجه، بنیاد به اندازهٔ کافی پایداری برای پیاده‌سازی سازگار با CatalystUI فراهم کند.

در نتیجه، Python وضعیت CatalystUI Verified برای زبان‌های برنامه‌نویسی را دریافت نکرده است.

#### فرض‌های بازبینی

این بازبینی خود Python و کتابخانهٔ استاندارد همراه آن را ارزیابی می‌کند.

بسته‌های شخص ثالث، افزونه‌های خاص پیاده‌سازی، ماژول‌های native اختیاری، type checkerهای خارجی، transpilerها و فریم‌ورک‌های سفارشی runtime به عنوان پشتیبانی سطح زبان در نظر گرفته نمی‌شوند.

### هشدارها

* Python integerهای با دقت نامحدود فراهم می‌کند، نه primitiveهای integer با عرض ثابت.
* `float` در Python معمولاً double precision است، اما یک خانوادهٔ جداگانه با عرض ثابت نیست.
* برخی رفتارهای حافظهٔ سطح پایین ممکن است به `ctypes` یا رفتار خاص پیاده‌سازی نیاز داشته باشند.
* type hintهای Python در runtime الزام نمی‌شوند.
* Python از propertyها پشتیبانی می‌کند، اما رفتار setter ممکن است حذف شود.
* Python می‌تواند چندین structure را از طریق امکانات کتابخانهٔ استاندارد مدل کند، اما نه به عنوان یک نوع structure native.

### شکست‌ها

* Python بیشتر نوع‌های عددی scalar با عرض ثابت مورد نیاز را فراهم نمی‌کند.
* Python یک نوع ممیز شناور scalar ۳۲ بیتی اختصاصی فراهم نمی‌کند.
* Python constantهای واقعی سطح زبان فراهم نمی‌کند.
* Python procedureها را جدا از functionها تعریف نمی‌کند.
* Python پشتیبانی pointer native فراهم نمی‌کند.
* Python پشتیبانی interface native فراهم نمی‌کند.
