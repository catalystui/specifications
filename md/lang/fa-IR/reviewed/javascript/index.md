# جزئیات بازبینی

## JavaScript

### نمای کلی

زبان برنامه‌نویسی JavaScript در برابر مشخصات FDEFSPEC (Rev. 1) و FRELSPEC (Rev. 1) تا تاریخ ۷ ژوئیهٔ ۲۰۲۶ بازبینی شده است.

#### بیانیهٔ بازبینی

هرچند JavaScript می‌تواند برخی مفاهیم لازم را از طریق objectها، functionها، arrayها و رفتار داخلی زبان نمایش دهد، این سازوکارها برای برآورده‌کردن مشخصات قابل‌اعمال CatalystUI در سطح زبان کافی نیستند.

این بازبینی خود JavaScript را ارزیابی می‌کند، نه اکوسیستم پیرامون JavaScript را. Browser APIها، Node.js APIها، Deno APIها، Bun APIها، Web APIها، TypeScript، WebAssembly، کتابخانه‌های خارجی و اعتبارسنجی سفارشی به عنوان پشتیبانی سطح زبان در نظر گرفته نمی‌شوند.

از آن‌جا که JavaScript بسیاری از نوع‌های عددی scalar با عرض ثابت مورد نیاز را ندارد، رمزگذاری‌های متن لازم را به عنوان قابلیت‌های زبان فراهم نمی‌کند، و چندین سازهٔ لازم برای سیستم، حافظه، threading و composite را تعریف نمی‌کند، ما باور نداریم JavaScript بدون زیرساخت اضافی قابل‌توجه، بنیاد به اندازهٔ کافی پایداری برای پیاده‌سازی سازگار با CatalystUI فراهم کند.

در نتیجه، JavaScript وضعیت CatalystUI Verified برای زبان‌های برنامه‌نویسی را دریافت نکرده است.

#### فرض‌های بازبینی

این بازبینی یک معیار سخت‌گیرانهٔ سطح زبان را اعمال می‌کند. اگر یک provision به‌صورت صریح توسط خود JavaScript پشتیبانی نشده باشد، به عنوان تأییدنشده علامت‌گذاری می‌شود.

APIهای فراهم‌شده توسط host، رفتار خاص پیاده‌سازی، کتابخانه‌های خارجی، transpilerها، سیستم‌های نوع و اعتبارسنجی سفارشی runtime از تأیید کنار گذاشته می‌شوند.

### هشدارها

* JavaScript می‌تواند بسیاری از مقدارهای عددی را از طریق `Number` نمایش دهد، اما `Number` یک نوع عددی ممیز شناور ۶۴ بیتی است.
* JavaScript نوع `BigInt` را فراهم می‌کند، اما `BigInt` با عرض دلخواه است.
* typed arrayها نمای ذخیره‌سازی دودویی فراهم می‌کنند، نه نوع‌های scalar زبان.
* رشته‌های JavaScript از code unitهای UTF-16 استفاده می‌کنند، نه مقدارهای صریح رمزگذاری متن.
* `const` از bindingها محافظت می‌کند، نه از مقدارهای object.

### شکست‌ها

* JavaScript بیشتر نوع‌های عددی scalar با عرض ثابت مورد نیاز را فراهم نمی‌کند.
* JavaScript یک نوع ممیز شناور scalar ۳۲ بیتی اختصاصی فراهم نمی‌کند.
* JavaScript، ASCII، CP1252، UTF-8 یا UTF-16LE را به عنوان رمزگذاری متن سطح زبان فراهم نمی‌کند.
* JavaScript سازه‌های file یا stream سطح زبان فراهم نمی‌کند.
* JavaScript سازه‌های address یا pointer سطح زبان فراهم نمی‌کند.
* JavaScript سازه‌های process، thread یا dispatcher سطح زبان فراهم نمی‌کند.
* propertyهای JavaScript یک member کلیددار صریح با accessor map لازم Get/Set فراهم نمی‌کنند.
* JavaScript ساختارها یا interfaceها را فراهم نمی‌کند.
