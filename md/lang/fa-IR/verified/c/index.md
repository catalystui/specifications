# جزئیات تأیید

## C

### نمای کلی

![Verified Indicator](https://www.catalystui.org/images/verification/verified-logo-generic.png)


زبان برنامه‌نویسی C در برابر مشخصات FDEFSPEC (Rev. 1) و FRELSPEC (Rev. 1) تا تاریخ ۷ ژوئیهٔ ۲۰۲۶ تأیید شده است.

#### بیانیهٔ حسن نیت

ما با حسن نیت باور داریم که زبان برنامه‌نویسی C می‌تواند مفاهیم و provisionهای تعریف‌شده در مشخصات زیر را به‌صورت معقول نمایش دهد و می‌تواند برای پیاده‌سازی سیستم‌هایی استفاده شود که با این مشخصات سازگار هستند.

#### بیانیهٔ بازبینی

C پشتیبانی سطح پایین قدرتمندی برای نمایش دادهٔ بنیادی، دسترسی به حافظه، fileها، streamها، procedureها، functionها، structureها و پیاده‌سازی مستقیم سیستم‌محور فراهم می‌کند.

هرچند C چندین سازهٔ composite شیءگرا را به‌صورت native فراهم نمی‌کند، این محدودیت‌ها به provisionهای composite خاص FRELSPEC محدود هستند و در زیر مستند شده‌اند. این شکست‌ها مانع از آن نمی‌شوند که C به‌طور کلی درون مشخصات در نظر گرفته شود، اما هنگام استفاده از C برای پیاده‌سازی‌های سازگار با CatalystUI باید فهمیده شوند.

#### فرض‌های بازبینی

این بازبینی پشتیبانی C استاندارد مدرن را فرض می‌کند، جایی که قابلیت‌های وابسته به نسخه مشخص شده‌اند. پشتیبانی از integerهای exact-width فرض می‌کند که نوع‌های متناظر `<stdint.h>` توسط پیاده‌سازی فراهم شده‌اند.

این بازبینی C را به عنوان یک زبان نمایش سطح پایین در نظر می‌گیرد. رمزگذاری‌های دقیق بر حسب byte می‌توانند مستقیماً از طریق آرایه‌های byte، جدول‌های lookup و منطق parsing صریح نمایش داده شوند، وقتی codec استاندارد نام‌گذاری‌شده‌ای فراهم نشده باشد.

### هشدارها

* نوع‌های integer با عرض دقیق به پشتیبانی پیاده‌سازی وابسته‌اند.
* CP1252 می‌تواند byte به byte نمایش داده شود، اما codec استاندارد نام‌گذاری‌شده‌ای فراهم نشده است.
* serialization برای UTF-16LE به مدیریت صریح ترتیب byte نیاز دارد.
* threadهای استاندارد ممکن است توسط برخی پیاده‌سازی‌های C حذف شده باشند.
* الگوهای شیءگرا می‌توانند به‌صورت دستی شبیه‌سازی شوند، اما سازه‌های native زبان نیستند.

### شکست‌ها

* C memberهای method native فراهم نمی‌کند.
* C propertyهای native فراهم نمی‌کند.
* C classهای native فراهم نمی‌کند.
* C interfaceهای native فراهم نمی‌کند.
