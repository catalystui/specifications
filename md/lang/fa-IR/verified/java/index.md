# جزئیات تأیید

## Java

### نمای کلی

![Verified Indicator](https://www.catalystui.org/images/verification/verified-logo-generic.png)


زبان برنامه‌نویسی Java در برابر مشخصات FDEFSPEC (Rev. 1) و FRELSPEC (Rev. 1) تا تاریخ ۷ ژوئیهٔ ۲۰۲۶ تأیید شده است.

#### بیانیهٔ حسن نیت

ما با حسن نیت باور داریم که زبان برنامه‌نویسی Java می‌تواند بخش بزرگی از مفاهیم و provisionهای تعریف‌شده در مشخصات زیر را به‌صورت معقول نمایش دهد و می‌تواند برای پیاده‌سازی سیستم‌هایی استفاده شود که با این مشخصات سازگار هستند.

#### فرض‌های بازبینی

این بازبینی پشتیبانی زبان Java مدرن را فرض می‌کند، جایی که قابلیت‌های وابسته به نسخه مشخص شده‌اند. قابلیت‌هایی مانند local variable inference، recordها و foreign memory access ممکن است به نسخه‌های جدیدتر Java نیاز داشته باشند.

### هشدارها

* Java پشتیبانی native برای نوع‌های عددی unsigned ندارد، که ممکن است برای برخی provisionها به widening یا نمایش‌های جایگزین نیاز داشته باشد.
* رفتار direct memory address و pointer-style ممکن است به پشتیبانی Java 22+ Foreign Function and Memory API نیاز داشته باشد.
* Java نحو property native ندارد و به جای آن به methodهای getter و setter نیاز دارد.

### شکست‌ها

* Java، CP1252 را به عنوان charset استاندارد تضمین‌شده فراهم نمی‌کند و برای سازگاری کامل به پشتیبانی خاص پیاده‌سازی، کتابخانه‌های اضافی یا handling سفارشی نیاز دارد.
* propertyهای Java یک member کلیددار صریح با accessor map لازم Get/Set فراهم نمی‌کنند.
